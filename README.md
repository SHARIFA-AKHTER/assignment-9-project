# Coupon Collecting Application

## Purpose
This project is a coupon-collecting web application that allows users to explore brands, view available coupons, and collect them for discounts. It provides a seamless user experience with features like authentication, profile management, and interactive UI components.

## Key Features
1. **Authentication**: 
   - Login, Register, and Forgot Password options.
   - Social login with Google integration.
   - Secure password validation and toggling.

2. **Brand and Coupon Management**:
   - View all available brands with detailed information, search functionality, and filters.
   - Private coupon pages displaying codes with "Copy Code" and "Use Now" buttons.

3. **Responsive Design**:
   - Fully responsive for mobile, tablet, and desktop devices.

4. **Dynamic Content**:
   - Brand and coupon data loaded from JSON.
   - Brand details and coupon codes dynamically rendered.

5. **Profile Management**:
   - Update user information (name, photo URL) from the My Profile page.

6. **Additional Features**:
   - Forgot Password redirect and logout for user security.
   - Bouncing text animations for sale notifications.
   - Animations on the home page using AOS.

7. **Error Handling**:
   - 404 error page with navigation to Home.

8. **SEO Optimization**:
   - SEO-friendly page titles and meta tags.

## Pages Overview
- **Home Page**: Includes a banner slider, top brands in a marquee, brands on sale, and additional sections.
- **Brands Page**: List of all brands with search and detailed cards.
- **Coupon Page** (Private): Coupon details with copy and use functionality.
- **My Profile Page** (Private): View and update user profile.
- **About Us Page**: Developer information and skills.
- **404 Page**: Redirects to Home.

## Technologies Used
- **Frontend**: React, React Router, Tailwind CSS
- **State Management**: Context API
- **Animations**: AOS (Animate on Scroll)
- **Clipboard Functionality**: `react-copy-to-clipboard`
